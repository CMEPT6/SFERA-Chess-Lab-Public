# CMEPT6 Engine 1.1 — шахматный движок и независимая турнирная лаборатория

**Язык:** C++17. **Лицензия:** MIT. **Платформа:** Windows 10/11 x64 (native EXE при сборке на Windows), Linux x64 (готовый бинарник). **Протокол:** UCI. **Статус:** работоспособный исследовательский релиз; сила пока не измерена достоверным рейтингом Elo.

## Что изменилось относительно 1.0

- Добавлена **самостоятельная Python-реализация правил стандартных шахмат** (`tests/referee.py`). Турнирный арбитр не обращается к внутренней нестандартной команде `status` CMEPT6, так что движок не может сам объявить свой результат.
- Новый `tests/tournament.py`: парные дебюты с перестановкой цветов, проверка легальности каждого хода, трикратное повторение, 50-ходовое правило, маты, паты, нештатное завершение двигателя и лимит длины партий.
- Выгрузка в **PGN**, **JSONL** (все ходы и технические причины) и **JSON** (сводка). Незавершённые игры имеют результат `*` и **не считаются ничьими**.
- Файл из 34 проверенных дебютных продолжений `tests/openings_uci.txt`. Возможна замена на свою, более длинную коллекцию. Каждая дебютная позиция играется обоими цветами.
- GitHub Actions для сборки и тестов нативного Windows x64 EXE и Linux x64; улучшен `build_windows.bat`.
- Шахматное ядро 1.0 **сохранено без изменений в алгоритме поиска**. Имя UCI изменено на CMEPT6 Engine 1.1. Эта версия повышает качество тестирования, а **не доказанную игровую силу**.

## Запуск Linux

```bash
chmod +x bin/linux/cmept6-engine
./bin/linux/cmept6-engine
```

Введите команды UCI: `uci`, `isready`, `position startpos`, `go depth 8`. Для отображения доски нужен шахматный GUI (Arena, Cute Chess, Banksia, SFERA Chess Lab).

## Получение Windows EXE

**Сейчас в архиве нет заранее скомпилированного Windows EXE.** Установите Visual Studio Build Tools (Desktop development with C++), откройте **x64 Native Tools Command Prompt** в папке проекта и запустите:

```bat
build_windows.bat
```

Результат: `CMEPT6-Engine.exe`. Либо загрузите проект в репозиторий GitHub и запустите workflow **CMEPT6 1.1 - Windows x64 release**. После успешной сборки и тестов GitHub отдаст артефакт `CMEPT6-Engine-1.1-Windows-x64`. Workflow включён, но из этой среды запуск Windows не выполнялся. Подробнее в [BUILD_WINDOWS.md](BUILD_WINDOWS.md).

## Запуск матчей (Python 3.10+, без pip-зависимостей)

Linux:

```bash
python3 tests/tournament.py \
  --a bin/linux/cmept6-engine --b reference/v0_4/cmept6-engine \
  --name-a 'CMEPT6 1.1' --name-b 'CMEPT6 0.4' \
  --games 40 --depth 4 --max-plies 180 \
  --out results/my_match
```

Windows (в PowerShell; при наличии файлов `CMEPT6-Engine.exe` и `CMEPT6-Old.exe`):

```powershell
python tests/tournament.py --a .\CMEPT6-Engine.exe --b .\CMEPT6-Old.exe --name-a "CMEPT6 1.1" --name-b "CMEPT6 old" --games 40 --movetime 100 --out results/my_match
```

Если у вас нет старой версии, используйте в обоих аргументах один EXE: это проверит протокол и арбитраж, **не сравнит силу**. Общее ограничение `--max-plies` по умолчанию 180, невыполненные партии записываются как `*`, а не как ничьи.

Для собственных дебютов: `--openings-file tests/openings_uci.txt`; формат каждой строки `Название|e2e4 e7e5 g1f3 b8c6`. Большие Elo-эксперименты требуют сотен **различных** дебютных позиций и статистически корректной процедуры. Файл на 34 дебюта служит для инженерных тестов, не профессионального рейтингования.

### Файлы результатов

- `results/my_match.pgn` — партии в формате PGN с SAN-нотацией.
- `results/my_match.jsonl` — ход, причина окончания, результат и диагностика каждой партии.
- `results/my_match.summary.json` — W/D/L, незавершённые партии, набранные очки и **только ориентировочный** Elo; он не заменяет доверительные интервалы и SPRT.

Движок не подтверждает результат матча: `tests/referee.py` проверяет правила независимо. Арбитр рассчитан на **обычные шахматы**, не Chess960, и автоматически заявляет доступные ничьи по трёхкратному повторению и правилу 50 ходов.

## Ограничения движка

- Классическая эвристическая оценка вместо обученной NNUE; один поток поиска.
- Гибрид Bitboards/0x88, нет полного Magic Bitboards; поиск и время недостаточно оптимизированы.
- Без Syzygy и Chess960; сила не сопоставима с современной вершиной движков.
- Не заявляем улучшения Elo версии 1.1 против 1.0, потому что шахматный алгоритм не изменялся.
- Для достоверного рейтинга необходимы быстрый независимый матч-раннер (например, fastchess), богатый проверенный набор дебютов и сотни/тысячи партий по каждому изменению.
