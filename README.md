# SFERA Chess Lab — Public Council Mirror

Публичное зеркало SFERA Chess Lab для независимого аудита, code review, benchmarks и SFERA Council.

**Baseline:** SFERA Chess Lab v1.5 — SFERA REPORT.

> THINK · LEARN · DISCOVER · CREATE

## Цель
SFERA — не клон ChessBase/Aquarium и не GUI для Stockfish. Это локальная исследовательская система, которая связывает партии, Position Genome, движки, статистику, память, Discovery, Research Tree и Teacher в единый workflow.

## Для AI Council
1. Прочитать `council/PROJECT_CHARTER.md`.
2. Прочитать `council/COUNCIL_RULES.md`.
3. Начать с `council/TASK-0001_FOUNDATION_AUDIT.md`.
4. Если исходного файла/модуля нет в репозитории — писать `NOT VERIFIED`, а не выдумывать аудит.

## Public mirror safety
Здесь не публикуются пользовательские базы, `sfera.sqlite3`, PGN-архивы, движки, TWIC-файлы, `.venv`, токены, резервные копии и приватная память.

## Council principle
**Evidence over votes.** Решение побеждает тестом/benchmark, а не количеством моделей, которые с ним согласились.
