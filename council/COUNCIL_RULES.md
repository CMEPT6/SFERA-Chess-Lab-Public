# SFERA COUNCIL — RULES

## 1. BLIND ROUND
Каждый участник решает задачу независимо. До сдачи своего решения ответы других моделей не читать.

## 2. CROSS REVIEW
После blind round участник получает 1–2 чужих решения и обязан найти сильные стороны, ошибки, риски и предложить проверяемое улучшение.

## 3. BENCHMARK
Спор решается тестом/benchmark, а не авторитетом модели.

## 4. MERGE
ChatGPT / Chief Architect фиксирует ADR, выбирает части решений и формирует merge plan.

## 5. RELEASE
Новая версия только после тестов, проверки миграций и rollback plan.

## Формат ответа
`MODEL / ROLE / TASK_ID / FINDINGS / SOLUTION / PATCH / TESTS / BENCHMARK / RISKS / WHAT_I_REJECTED / CONFIDENCE`
